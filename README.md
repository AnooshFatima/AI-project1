# Rule-Based AI Chatbot using Python

## Project Description

This project is a simple Rule-Based AI Chatbot developed using Python. The chatbot interacts with users by responding to predefined inputs using **if-elif-else** conditions. It demonstrates the basic concepts of Artificial Intelligence, decision-making, and control flow without using Machine Learning.

The chatbot runs continuously until the user enters an exit command.

---

## Features

* Greets the user with predefined responses.
* Introduces itself when asked.
* Answers basic questions about Artificial Intelligence.
* Responds to "Thank You" messages.
* Handles exit commands (`bye`, `exit`, `quit`).
* Displays a default response for unknown inputs.
* Runs continuously using a `while` loop.

## Project Workflow

1. Import the required functions.
2. Define chatbot response rules.
3. Accept user input.
4. Convert input to lowercase.
5. Check user input using **if-elif-else** statements.
6. Display the appropriate response.
7. Continue the conversation until the user enters an exit command.
8. End the program gracefully.
